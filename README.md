# Data Management Example Workflows

This repository contains small, reproducible examples of how I work with data in R and Python, including:

- Data cleaning and harmonization  
- Reproducible processing pipelines  
- Handling multicenter datasets  
- Survival analysis (Cox regression)  
- Memory-efficient workflows  

These examples reflect my approach as a data manager:
- Raw data untouched  
- Versioned cleaned datasets  
- Script-based processing  
- Clear documentation
